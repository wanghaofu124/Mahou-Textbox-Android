# 魔裁 0.7.23

版本：0.7.23 / versionCode 54。此版本以预发布 APK 提供。

- 修复内置键盘触摸事件取消点击的问题，恢复字母键、候选词和语音按钮的点击响应。
- 拼音词库加载期间保留输入，不再因 1.8 秒超时反复销毁工作线程；减少快速输入时堆积的候选查询。
- 加大内置键盘按键和预输入区域，并为短屏设备保留紧凑尺寸。
- 键盘编辑时跳过不必要的整图重绘，减少台词输入延迟。
- 语音识别服务不可用或启动失败时，尝试打开手机的语音识别界面并回填识别文字。

语音识别是否可用仍取决于手机的语音服务和麦克风权限；需要在目标手机上确认识别界面能否打开及文字能否回填。
