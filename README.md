# 魔裁文本框：Android 图片输入法与对话框生成器

**当前源码：0.7.24（versionCode 55）**

[下载 0.7.24 预发布 APK](https://github.com/wanghaofu124/Mahou-Textbox-Android/releases/tag/v0.7.24)

魔裁可以在输入法内选择角色、表情和背景，编辑台词并生成 PNG 表情图；仓库也保留了原有 Python 桌面脚本。

## Android 版功能

- 图片输入法：在输入法内编辑图片和台词，支持拼音键盘、表情与背景切换。
- 文字编辑键盘：可选手机原键盘或魔裁内置键盘；语音识别由手机配置的识别服务提供。
- QQ/TIM 图片流程：先尝试 Android 图片输入接口；QQ 不接收时将 PNG 保存到相册，并提示点聊天输入框右侧“+”→“相册”选择图片。
- 常驻悬浮窗：支持拖动、缩放、最小化和 70%～100% 内容透明度。
- 素材管理：支持导入、缩放裁切、重命名、排序和删除确认。
- 自定义角色：支持角色表情组和可拖动的姓名字块。
- 本地备份：可导出、恢复 `.mahou-backup`，方便更换安装包或设备。
- 隐私：应用不申请网络权限，台词和自定义素材保存在本机；手机语音识别服务是否联网由该服务决定。
- 无障碍支持：关键操作和悬浮窗控制可由 TalkBack 读取并执行。

## 使用与发送

首次使用时，在系统设置中启用“魔裁图片输入法”。使用 QQ/TIM 时，在目标聊天切换到魔裁，编辑图片后点“放入 QQ”。如果 QQ 拒绝直接接收，按提示点输入框右侧“+”→“相册”，选择最新的魔裁图片。最终发送由用户在 QQ/TIM 内完成；应用不自动选择联系人或代发消息。

文字编辑键盘可在主界面设置中切换。使用手机原键盘时，编辑结束后系统可能要求手动选回魔裁；使用内置键盘可留在魔裁流程中。内置语音输入通过手机语音识别界面完成。首次使用悬浮窗模式还需允许“显示在其他应用上层”。

当前图片导出格式为 PNG，GIF 导出尚未实现。0.7.24 为预发布版本，QQ/TIM 的实际发送流程和手机语音识别需在目标设备上确认。更新内容见 [发布说明](android_apk/RELEASE_NOTES-0.7.24.md)。

## Python 桌面版（原版脚本）

本仓库基于 [oplivilqo 的项目](https://github.com/oplivilqo) 二次开发，在保留原版功能的基础上修复了快捷键阻塞、输出图片角色名丢失等 bug，并新增窗口白名单、系统 emoji 支持等功能。

### 功能特色

- 多角色支持：内置 14 个角色，每个角色多个表情差分
- 快捷键操作：全键盘操作，无需鼠标点击
- 智能合成：自动合成背景与角色图片
- 文本嵌入：自动在表情图片上添加文本
- 随机算法：智能避免重复表情
- 自动保存：生成图片自动保存到用户文档目录

### 使用方法

输入文本 → 切换角色 → 按 Enter 生成图片并发送；Tab 键清理临时图片缓存。
