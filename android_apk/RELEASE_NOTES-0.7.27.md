# 魔裁 0.7.27

版本：0.7.27 / versionCode 58。此版本以预发布 APK 提供。

- 内置语音改用 Vosk 中文离线识别，不再依赖 Vivo 当前无法工作的系统识别服务。
- 首次使用时在应用内下载并校验约44MB中文模型；安装后模型约占用68MB应用私有存储空间。后续识别可离线完成。
- 键盘预输入区显示模型准备进度和识别中的文字；准备期间再次点麦克风可取消，识别期间再次点可结束并插入识别文字。
- 修正双击预览进入编辑时焦点状态不同步导致输入文字暂时不可见的问题。

模型下载需要网络和约120MB临时可用空间（模型压缩包与解压文件同时存在）。已在 Vivo 真机确认模型下载、离线中文识别和识别结果插入台词；本次未验证 QQ/TIM 的图片发送流程。
