# 魔裁文本框 0.4.0

版本号：`0.4.0`（versionCode `23`）

## 主要变化

- 悬浮窗升级为用户主动启动的 `specialUse` 前台服务，通知提供恢复和关闭操作。
- 分享采用明确状态机：生成图片、隐藏悬浮窗、打开外部分享、返回后单次恢复。
- 自定义素材索引升级到 manifest v3，记录 MIME、字节数与 SHA-256，并迁移旧格式和错误扩展名。
- 新增 `.mahou-backup` 备份与事务恢复，包含容量、哈希、条目数和 Zip Slip 检查。
- 图片导入处理 EXIF 旋转/翻转、透明 PNG、采样解码以及单图 20 MB/总量 200 MB 限制。
- WebView 仅加载 `appassets.androidplatform.net` 本地可信内容，APK 移除 `INTERNET` 权限并加入 CSP。
- 无障碍虚拟节点使用网页控件真实范围，支持主操作、悬浮窗控制及透明度入口。
- 修复 Android 15 系统栏遮挡与迷你工具条分享无法解码 PNG 的问题。

## 安装与升级

正式版必须永久沿用当前 Release 证书。首次从旧 Debug 包切换到 Release 包时签名不同，需先在旧包导出备份，再卸载、安装 Release 并恢复；后续 Release 可直接覆盖升级。

应用不会联网检查更新，请从原下载渠道手动获取新版本。

## 已知边界

- QQ/TIM 目标应用的图片读取和群聊手动发送必须在 Android 13+ 真机上作最终验收。
- 主界面为竖屏优先设计；悬浮窗会在屏幕尺寸变化时重新夹取位置。
- 应用不能自动选择 QQ 群或替用户发送消息。
