# 魔裁文本框 APK 0.4.0 发布审查报告

**版本**：0.4.0（versionCode 23）  
**目标 SDK**：35  
**最低 SDK**：23  
**发布状态**：Release Candidate，等待 Android 13+ 真机 QQ/TIM 验收

## 构建与安全

- 标准 Gradle/AndroidX Java 工程，Debug 与 R8 Release 独立构建。
- Release 密钥不自动生成，构建时固定核对 `release-cert.sha256`。
- Release 不可调试，不执行 `mahou_test_action`，不包含 `INTERNET` 权限。
- WebView 仅加载本地可信 HTTPS 源；关闭 file/content 访问、跨域 file URL 和混合内容。
- 自定义素材位于 App 私有目录，Android 系统云备份和设备迁移备份均关闭。

## 自动化覆盖

- Java 单元测试、Android lint、Debug/Release 构建、R8、签名与版本验证。
- 透明 PNG、旧 PNG-in-JPG 迁移、损坏 manifest 备份、角色级联删除。
- 备份往返、同 ID 合并、哈希与路径检查、Zip Slip 拒绝及失败不改动原数据。
- API 35 Pixel_9：主界面、素材管理、备份取消、通知允许/拒绝、前台服务、悬浮窗恢复/关闭、迷你分享和分享返回。
- 无障碍节点范围、Android 15 状态栏/导航栏 Insets、PNG 系统分享预览。

## 未完成的公开发布门槛

- 当前环境没有 API 23/29 系统镜像，尚未执行这两档模拟器回归。
- 当前 adb 未连接真机，尚未验证 Android 13+ 真机 QQ/TIM 群聊发送、通知后台回收和从旧 Debug 备份迁移到 Release。
- 以上门槛完成前，Release APK 应标记为候选版，不宣称最终公开正式版。
