# 魔裁文本框 0.5.0 交互重做候选版

版本：0.5.0，versionCode 24。本轮先交付可安装成品，不将未执行的测试列为通过。

## 界面与聊天操作

- 重做主界面和悬浮聊天界面，发送区固定到底部，不再滚动寻找 QQ 和分享按钮。
- 角色、表情、背景改为缩略图总览，可搜索、显示当前选择。
- 窗口控制改为图标按钮，拖动和缩放使用触摸阈值、逐帧更新、屏幕边界夹取和近边吸附。
- 收起后为独立位置的 56dp 浮钮；点击恢复，长按可发到 QQ、分享或关闭。
- 首次从旧版升级时将旧贴边栏尺寸迁移成 360dp × 480dp 小窗，位置自动限制在可见范围；之后记住用户调整的尺寸。
- 输入时临时避让键盘，完成输入后恢复布局；收起和分享时释放输入焦点。
- 素材面板临时展开，退出后回到原窗口；系统返回键优先关闭当前面板。
- 透明度只影响内容，原生控制区保持清晰；设置入口中可调 70% 至 100%。

## 分享与状态

- 主界面与悬浮窗共享带版本号的生成状态，仅提交变动字段，避免互相覆盖台词。
- PNG 在后台校验和写入，避免主线程重复解码、压缩。
- 分享使用统一代理页面和结果回调；外部分享期间隐藏悬浮窗，返回后恢复一次，不再通过固定 30 秒计时器提前弹回。
- 选图、备份、恢复时隐藏悬浮窗；完成或取消后返回原窗口。
- QQ、TIM、系统分享降级保留。应用不能自动选群，也不能替用户点击发送。

## 素材编辑

- 裁切支持拖动、滑条缩放、双指缩放和重置；保存/取消固定在顶部。
- 背景始终覆盖裁切范围；角色定位保留透明边距并限制不能完全拖出画布。
- 保存图片使用实际裁切变换，不把棋盘格背景写进素材。
- 素材增加改名、当前选择反馈和中文删除确认；自定义表情可前移、后移，最后一张禁止删除。
- 姓名字块保留拖动偏移，选中文字块后编辑内容、颜色和字号。
- 图片选择通过受限本地缓存 URL 传递，不再把完整图片放进系统消息，降低大图导入失败风险。
- 保留 EXIF 方向修正、透明 PNG、本地备份和容量保护；补强索引大小与恢复失败时原始素材保留。

## 安装

优先安装 `mahou-textbox-0.5.0-release.apk`。沿用现有发布证书，旧 Release 可覆盖安装；升级前建议先在素材管理导出备份。

Debug 与 Release 签名不同。旧 Debug 不能直接被 Release 覆盖，请先备份，再更换安装包并恢复。

本轮未上传 GitHub，也没有自动推送或创建公开 Release。

## 构建

`build_apk.ps1 -Configuration All -Quick` 直接构建并打包两种 APK，仍校验签名、版本、证书指纹和包体上限。

不带 `-Quick` 时保留完整静态检查和单元测试入口。该命令用于后续完整回归，不代表本轮已执行所有测试。

## 验证范围与边界

本轮以成品和实际交互为优先，验证构建、签名、本地页面与模拟器的核心操作。未执行 API 全矩阵、长时间压力测试和完整存储破坏性测试。

QQ/TIM 真机预览、群聊手动发送、不同厂商后台管理以及完整 TalkBack 流程仍需真机验收，不能将模拟器的系统分享降级等同于 QQ 已验收。
