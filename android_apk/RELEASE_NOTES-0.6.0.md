# 魔裁文本框 0.6.0 图片输入法试用版

版本：0.6.0 / versionCode 26。此版本为本地候选包，未发布到 GitHub，不代表已经通过真实 QQ/TIM 兼容性验证。

## 本轮重点

- 主界面和悬浮窗改成一体式编辑：台词输入框位于图片内部，点图片区或铅笔即可输入，不再占用独立文字面板。
- 图片下方只保留编辑、随机、清空、字数和收起键盘的紧凑工具栏。编辑时长文在图片文字区内滚动，收起后恢复最终图片排版，导出不包含编辑控件。
- 弹出键盘后按可用空间等比例缩小图片，不再隐藏整个预览。悬浮窗默认高度由 480dp 减至 400dp，旧默认尺寸自动更新，其他已调整尺寸保留。
- 新增真正的 Android 图片输入法，在系统键盘区域显示预览、角色、表情和背景选择，不再把悬浮窗覆盖在聊天上方。
- 支持“读取草稿”和“插入图片”。读取由用户主动触发，保留聊天框原文，超过 180 字时提示缩短，不读取密码框。
- 插入走 Android 图片输入接口，只向当前编辑器提交 PNG，不打开分享器，不自动选群或发送。
- 读取与插入反馈使用面板内短提示，不遮住底部按钮，不要求额外确认。
- 当前编辑器未声明图片支持时禁用插入按钮。可主动复制图片尝试粘贴，不静默退回选群分享。
- 右上角键盘图标切回文字键盘，系统侧滑返回可收起输入法。魔裁不替代原输入法的中文打字能力。
- 图片输入法在外部聊天启用时关闭悬浮窗，避免两种界面互相遮挡。打开魔裁自己的台词编辑区时切回文字键盘。
- 主界面新增“聊天模式”入口，集中提供启用输入法、切换输入法和打开悬浮窗。
- 修正素材缩略图网格在低高度窗口中挤压文字的问题，素材多时正常滚动。
- 悬浮窗补上 Android 新返回手势适配，编辑或素材面板获取焦点时使用对话框式交互；普通悬浮状态保持不抢下层应用焦点。

## 首次启用

1. 安装 Release APK，打开“聊天模式”与“启用图片输入法”。系统显示第三方输入法安全提醒后，由你决定是否启用。
2. 在 QQ 当前群聊里用原来的文字输入法写台词，再通过系统键盘切换按钮选择“魔裁图片输入法”。
3. 点“读取草稿”，调整素材，点“插入图片”。目标应用接收后，由你在聊天里确认发送。原台词草稿不会自动清除。

图片输入法也可使用主界面已有的台词与选择。自定义素材仍在主界面管理，输入法内只做快速选择。

## 兼容性与隐私

- 目标应用必须支持 Android 图片输入；不能据此保证所有 QQ/TIM 版本都能插入。若显示“当前输入框不接收图片”，这个聊天编辑器没有声明相应能力。
- “复制图片”是否能在 QQ 粘贴也取决于 QQ 自身支持。普通 QQ 分享仍然会打开 QQ 的选联系人和确认页。
- 不使用无障碍自动点按、读取聊天记录、模拟发送或非公开 QQ 接口。
- 无联网权限。台词、素材与生成都在本机；主动插入或复制时，图片才交给当前应用或系统剪贴板。
- 生成的输入法图片用独立缓存文件提供临时读取权限；缓存按时间清理，不能作为永久素材地址。

## 已执行的针对性交互验证

- Android 15 Pixel 模拟器、手势导航：键盘区域完整显示预览、选择器和底部操作。
- 独立 UID 的图片接收应用：读取当前草稿后，实际收到并解码 1000 x 326 PNG，原草稿保留，未打开任何分享或联系人选择页。
- 未声明图片接收能力的短信编辑器：插入按钮禁用，不误报兼容。
- 素材总览可打开并选择角色；320px 和 411px 宽度检查卡片文字布局。
- 侧滑返回可收起图片输入法。
- 图片输入法右上角键盘按钮已实际切回系统文字键盘；为新版 Android 补充输入法服务可见性声明，并在系统上一输入法切换无效时提供兜底。
- 悬浮窗打开素材管理后侧滑返回小窗；编辑台词时侧滑收起文字键盘。此结论限本次模拟器，不代表所有厂商系统均已验证。
- 一体式编辑：320px 主界面和 204px 高的小窗检查图片内输入、长文区内滚动及 PNG 导出；模拟器实际弹出文字键盘后，主界面和悬浮窗的图片内输入区、工具栏、发送按钮均可见。旧默认小窗高度已迁移为 400dp。

本轮按用户要求优先完成可用功能与直接交互验证，没有运行大规模数据测试或完整设备矩阵。真实手机上的 QQ/TIM 插入、粘贴与最终手动发送仍未验证。

## 构建和安装

- `mahou-textbox-0.6.0-release.apk`：沿用既有正式签名，日常试用选此包。
- `mahou-textbox-0.6.0-debug.apk`：测试签名，仅用于开发排查，不能直接覆盖正式包。
- 安装前建议在素材管理中导出备份。签名相同可升级；若旧包为 Debug 签名，需要先备份再更换安装，不要直接卸载丢失自定义素材。
- 本轮使用快速构建，仍检查 APK 签名、固定证书、版本和大小，并生成 SHA-256 校验文件；不把未运行的完整测试记为通过。
