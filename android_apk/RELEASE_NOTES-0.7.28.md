# 魔裁 0.7.28

版本：0.7.28 / versionCode 59。此版本以预发布 APK 提供。

- 修复 WebView 渲染进程退出后输入法页面可能整块黑屏的问题：输入法重新显示时检查页面状态，检测到页面失效会重建；主界面、编辑页和悬浮窗也能单独替换退出的 WebView。
- 输入法显示时提高其 WebView 渲染进程的优先级；主界面进入后台时降低优先级，减少低内存时输入页面被系统回收的概率。
- 增加网页加载失败和渲染进程退出日志，便于继续定位真机上的异常。

这台 Vivo 之前记录到 WebView 渲染进程在低内存时退出（RSS 约 273 MB）。本版已安装到连接设备；重新打开 QQ 输入法后，页面加载完成、自检通过且控件正常显示。输入文字后再次黑屏的完整触发过程仍需继续观察，尚未声称完全解决。
