# 魔法少女文本框 APK 0.3.8 发布与审查报告

**版本**：0.3.8（versionCode 22）  
**目标 SDK**：35  
**最低 SDK**：23

## 本版修复

- 透明素材会检测实际透明像素并保存为 PNG，普通照片保存为 JPEG。
- 图片导入先检查 20 MB 原图上限，再按尺寸采样解码，降低超大图片导致 OOM 的风险。
- 素材文件根据真实文件头使用 `.png` 或 `.jpg` 扩展名。
- 旧版 PNG 内容使用 `.jpg` 扩展名时会自动迁移，并同步更新 manifest。
- manifest 改为完整循环读取、临时文件写入、同步落盘及旧文件备份。
- 自定义素材总容量限制为 200 MB，超过限制时不会写入残缺文件。
- 浅色主题同时使用深色状态栏和导航栏图标；深色主题会清除两项浅色外观。
- “弹窗模式”只开启悬浮窗，不再自动打开 QQ 或把主界面退到后台。
- Debug 与 Release 使用独立构建配置；Release 不执行测试 Intent，也不输出 `MahouTest` 日志。

## 构建

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File android_apk/build_apk.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File android_apk/build_apk.ps1 -Configuration Release
powershell.exe -NoProfile -ExecutionPolicy Bypass -File android_apk/build_apk.ps1 -Configuration All
```

输出：

- `android_apk/mahou-textbox-debug.apk`
- `android_apk/mahou-textbox-release.apk`

首次构建 Release 时会创建：

- `android_apk/release.keystore`
- `android_apk/release-signing.properties`

这两个文件已被 `.gitignore` 排除，必须一起离线备份。后续正式版本必须永久复用它们，否则用户无法覆盖升级。

## 安装说明

Debug 与 Release 包名相同但签名不同。第一次从旧 Debug 包切换到 Release 包时，需要先卸载旧包；卸载会清除 App 私有目录中的自定义素材。后续 Release 版本只要沿用当前 release keystore，即可正常覆盖升级。

## 自动化测试

脚本优先读取 `ANDROID_SERIAL`，未设置时会选择第一台在线设备：

```powershell
android_apk/test_theme_prefs.ps1
android_apk/test_qq_features.ps1
android_apk/test_storage_migration.ps1
android_apk/test_release_security.ps1
```

覆盖内容：

- 版本、主题持久化、浅色状态栏与导航栏。
- 素材管理叠层实际打开与系统 Back 关闭。
- QQ/系统分享尺寸、悬浮窗迷你模式和透明 PNG 存储格式。
- Monkey 300 次事件及崩溃、ANR、URI、OOM 关键日志。
- Release 包不可调试且忽略 `mahou_test_action`。

- 四套主题检查 WebView、状态栏、导航栏和悬浮窗。
