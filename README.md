# 魔裁文本框：Android 悬浮式 GALGAME 对话框生成器

**最新版本：0.4.0（versionCode 23）**

[前往 Releases 下载正式版 APK](https://github.com/wanghaofu124/Mahou-Textbox-Android/releases/latest)

这是一个完全离线的 Android 对话框图片生成器，也保留了原有 Python 桌面脚本。你可以输入 QQ 群聊台词，选择角色、表情和背景，生成类似 GALGAME 的对话框图片，再通过 QQ、TIM 或系统分享发送。

## Android 版功能

- 常驻悬浮窗：支持拖动、缩放、最小化和 70%～100% 内容透明度。
- 分享后常驻：打开系统分享界面时暂时隐藏，返回后自动恢复原位置。
- 素材管理：内置背景、角色和表情总览，支持导入、裁切、重命名、排序与删除确认。
- 自定义角色：支持角色表情组和可拖动的姓名字块。
- 本地备份：可导出、恢复 `.mahou-backup`，方便更换安装包或设备。
- 完全离线：APK 不申请联网权限，台词和自定义素材只保存在本机。
- 无障碍支持：关键操作和悬浮窗控制可由 TalkBack 读取并执行。

首次使用弹窗模式时需要允许“显示在其他应用上层”。Android 13 及以上会询问通知权限，用来显示悬浮窗运行状态以及“恢复窗口/关闭”操作；拒绝后悬浮窗仍可使用。

受 Android、QQ 和 TIM 的安全限制，应用只能打开分享入口，不能自动选择群或代替用户发送消息。

> 0.4.0 当前为公开候选版，已通过 Android 15/16 模拟器测试；QQ/TIM 真机群聊发送仍建议在自己的设备上确认。

详细变化、安装说明和校验值见 [0.4.0 发布说明](android_apk/RELEASE_NOTES-0.4.0.md)。

## Python 桌面版（原版脚本）

本仓库基于 [oplivilqo 的项目](https://github.com/oplivilqo) 二次开发，在保留原版功能的基础上修复了快捷键阻塞、输出图片角色名丢失等 bug，并新增窗口白名单、系统 emoji 支持等功能。

### 功能特色

- 多角色支持：内置 14 个角色，每个角色多个表情差分
- 快捷键操作：全键盘操作，无需鼠标点击
- 智能合成：自动合成背景与角色图片
- 文本嵌入：自动在表情图片上添加文本
- 随机算法：智能避免重复表情
- 自动保存：生成图片自动保存到用户文档目录

### 使用方法

输入文本 → 切换角色 → 按 Enter 生成图片并发送；Tab 键清理临时图片缓存。
